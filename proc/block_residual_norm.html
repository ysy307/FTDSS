block_residual_norm

function block_residual_norm(r) result(norm)

L2 norm of a block residual with the constant (nullspace) mode removed. For all-Neumann blocks (e.g. a closed/flux-only hydraulic domain) the consistent residual is defined only up to an additive constant; projecting that mode out makes the residual-decrease criterion meaningful and universal, while leaving well-posed blocks essentially unchanged near convergence.

    function block_residual_norm(r) result(norm)
        implicit none
        real(real64), intent(in) :: r(:)
        real(real64) :: norm

        integer(int32) :: n
        real(real64) :: mean

        n = size(r)
        if (n <= 0) then
            norm = 0.0d0
            return
        end if

        mean = sum(r) / real(n, real64)
        norm = vector_norm2(r - mean)
    end function block_residual_norm
