type_vtu_writer

type, public, extends(abst_vtk_writer) :: type_vtu_writer

Extends @c abst_vtk_writer and delegates all operations to the C++ @c VtuWriter class via the ISO_C_BINDING interface above.

The type stores a single @c c_ptr handle; all VTK pipeline objects live on the C++ heap and are managed by @c VtuWriter via @c vtkSmartPointer.

Usage example @code type(type_vtu_writer) :: w call w%initialize("output_001.vtu") call w%write_mesh(num_pts, pts, num_cells, conn_sz, conn, offs, types) call w%write_scalar_point_data("temperature", num_pts, T) call w%write() call w%finalize() @endcode
