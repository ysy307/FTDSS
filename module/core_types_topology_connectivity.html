type, public ::  type_csr_index

Stores element connectivity in Compressed Sparse Row (CSR) format. This structure is used to represent the connectivity of nodes in a mesh, where each element node set is stored in a compact format for efficient access. The row_ptr array indicates the starting index of each element node set in the col_ind array, which contains the actual node IDs for all elements concatenated together.
