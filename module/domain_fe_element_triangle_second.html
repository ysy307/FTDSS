pure module subroutine calc_jacobian_triangle_second(self, r, node_coords, jac)

Calculates the Jacobian matrix. Standard definition: J(i, j) = d(x_i) / d(xi_j) J(1,1) = dx/dxi, J(1,2) = dx/deta J(2,1) = dy/dxi, J(2,2) = dy/deta
