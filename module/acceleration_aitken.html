Implementation overview

Algorithm: - Aitken delta-squared process for dynamic relaxation

Numerical considerations: - Relaxation factor is bounded by configuration limits to prevent instability - Fallback to previous relaxation factor if denominator is too small

Memory usage: - Stores one previous increment vector per physics type
