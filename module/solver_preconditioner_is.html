Module Subroutines
apply_preconditioner_is destroy_preconditioner_is initialize_preconditioner_is setup_preconditioner_is

I+S approximate inverse preconditioner for BSR matrices. Computes M^{-1} ≈ I + S where S ≈ I - A_scaled. A_scaled = D^{-1}A so that diagonal is identity, then S = I - A_scaled. Apply: z = (I + S) r = (2I - D^{-1}A) r = 2r - D^{-1}(Ar)

module subroutine apply_preconditioner_is(self, r, z)

Apply I+S: z = D^{-1}(2I - AD^{-1}) r. Step 1: work = Ar (SpMV) Step 2: work = D^{-1} * work (block solves) Step 3: z = 2r - work
