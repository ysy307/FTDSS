module subroutine initialize_type_matrix_csr(self, num_nodes, row, col, row_blocks, col_blocks)

Initializes the DOF-level csr matrix structure from a node-level adjacency pattern. It assumes the input node-level column indices (col) are sorted for each row segment. This routine expands the node-level graph into a full DOF-level matrix sparsity pattern.
