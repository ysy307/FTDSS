Functions

public function create_fe(id, integration_order) result(fe)

Creates a concrete finite element object based on a VTK cell type ID. This function acts as the public interface to the factory. If called for the first time, it will automatically initialize the internal constructor table.

Arguments

Type IntentOptional Attributes Name
integer(kind=int32), intent(in) :: id

The VTK cell type ID for the element to create.
integer(kind=int32), intent(in) :: integration_order

The integration order for the element.

Return Value class(abst_fe), allocatable

The newly allocated finite element object, or an unallocated object on failure.

private subroutine initialize_factory_internal()

Initializes the internal constructor table (factory). This routine allocates the table and registers all available finite element constructor procedures.

Arguments

None

private subroutine register_constructor(id, constructor)

Registers a constructor procedure for a given VTK cell type ID. If a constructor is already registered for the specified ID, it will be overwritten and a warning will be logged.

Arguments

Type IntentOptional Attributes Name
integer(kind=int32), intent(in) :: id

The VTK cell type ID to associate with the constructor.
procedure(abst_fe_constructor), intent(in), pointer :: constructor

A procedure pointer to the constructor function.
