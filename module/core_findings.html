binary_find

Functions
binary_find_int16 binary_find_int32 binary_find_int64 binary_find_int8 binary_find_real128 binary_find_real32 binary_find_real64

Provides a generic binary search function for finding a value in a sorted integer/real array.

Algorithm: Lower Bound (finds the first occurrence or first insertion point).


Uses

    • stdlib_optval
    • iso_fortran_env
