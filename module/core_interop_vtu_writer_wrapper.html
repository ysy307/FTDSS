@brief ISO_C_BINDING interfaces and concrete Fortran type for the VTK XML unstructured-grid writer.

Provides:

  • Low-level C-binding interfaces mapping directly to the @c c_vtu_writer_* functions in @c c_wrapper.cpp.
  • @c type_vtu_writer — concrete extension of @c abst_vtk_writer that holds an opaque @c c_ptr handle to a C++ @c VtuWriter object and delegates all operations through the C layer.

Calling chain

Performance Field arrays (scalar / vector) are passed directly to the C++ layer without heap copies via @c vtkDoubleArray::SetArray(). Connectivity is expected to be 0-based and is forwarded without temporary conversion arrays.


Uses

    • iso_c_binding
    • iso_fortran_env
