Abstract matrix type and five concrete storage formats: dense, CSR, COO, BSR (block sparse row), and DIA (diagonal).

All formats share a uniform API via the abst_matrix polymorphic interface. set_value (row,col) is restricted to dense; sparse formats use set_local_matrix or the search-free set_value_at(idx) addressing the flat value storage by position.
