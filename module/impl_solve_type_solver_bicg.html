Module Subroutines
destroy_type_solver_bicg initialize_type_solver_bicg solve_type_solver_bicg

BiConjugate Gradient (BiCG) solver for nonsymmetric systems. Uses two-sided Lanczos process with A and A^T. Since A^T is not explicitly available, we use the transpose-free formulation where r0_star serves as the left Krylov vector.

module subroutine solve_type_solver_bicg(self, A, b, x)

Solve Ax = b using preconditioned BiCG. Since we cannot form A^T explicitly, we use r0 as the shadow residual and apply the preconditioner symmetrically.
