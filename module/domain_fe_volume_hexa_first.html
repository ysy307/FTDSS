Implements the procedures for the first-order hexahedral (8-node) finite element. Trilinear shape functions on reference hexahedron [-1,1]^3.

Node numbering (VTK Hexahedron convention): 1(-1,-1,-1), 2(1,-1,-1), 3(1,1,-1), 4(-1,1,-1), 5(-1,-1,1), 6(1,-1,1), 7(1,1,1), 8(-1,1,1)
