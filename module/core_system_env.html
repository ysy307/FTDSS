public subroutine get_env_string(env_var_name, value, status)

Gets the value of a specified environment variable as a string. In an MPI environment, rank 0 reads the variable, which is then broadcast to all other ranks to ensure consistency.

Arguments

Type IntentOptional Attributes Name
character(len=*), intent(in) :: env_var_name

The name of the environment variable to retrieve.
character(len=:), intent(inout), allocatable :: value

The retrieved value of the environment variable. An empty string is returned if the variable is not set or is empty.
integer(kind=int32), intent(inout), optional :: status

Status code: 0 if successful, non-zero otherwise.
