Implements the procedures for the second-order hexahedral Serendipity (20-node) finite element. Quadratic Serendipity shape functions on reference hexahedron [-1,1]^3. 8 vertex nodes + 12 edge midpoint nodes. No face or interior nodes.

Node numbering (VTK QuadraticHexahedron convention): Vertices (1-8): standard hex ordering 1(-1,-1,-1), 2(1,-1,-1), 3(1,1,-1), 4(-1,1,-1) 5(-1,-1,1), 6(1,-1,1), 7(1,1,1), 8(-1,1,1) Edge midpoints (9-20): Bottom: 9(0,-1,-1), 10(1,0,-1), 11(0,1,-1), 12(-1,0,-1) Top: 13(0,-1,1), 14(1,0,1), 15(0,1,1), 16(-1,0,1) Vertical: 17(-1,-1,0), 18(1,-1,0), 19(1,1,0), 20(-1,1,0)

pure elemental module subroutine calc_psi_hexa_second_serendipity(self, i, r, psi_val)

20-node Serendipity shape functions. Vertex nodes (i=1..8): N_i = (1/8)(1+xi_ixi)(1+eta_ieta)(1+zeta_izeta)(xi_ixi+eta_ieta+zeta_izeta-2) Edge midpoint nodes (i=9..20): N_i = (1/4)(1-t^2) * product of (1+coord_j*val_j) for fixed coords where t is the free coordinate direction
