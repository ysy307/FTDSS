Interfaces
dasum ddot dnrm2 idamax pdasum pddot pdnrm2

Provides external function interfaces for the Intel Math Kernel Library (MKL). This entire module is only compiled if the _MKL preprocessor macro is defined. It includes interfaces for both standard and MPI-parallel BLAS routines.


Uses
