subroutine jacobi_equilibrate_bsr(K, F, D)

Symmetric Jacobi (diagonal) equilibration of a BSR linear system in place: with D_i = 1/sqrt(|A_ii|), form A <- D A D and b <- D b, returning D so the solution can be unscaled as x = D y. This restores conditioning of the strongly unit-disparate coupled (T, p_w) system (cond ~ 1e13 -> O(1)) so that even a direct solver returns an accurate increment. No-op for non-BSR matrices.
