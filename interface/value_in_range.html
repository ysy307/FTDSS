private pure function value_in_range_int8(value, min, max) result(in_range)

Checks if an int8 value is within the inclusive range [min, max].

Arguments

Type IntentOptional Attributes Name
integer(kind=int8), intent(in) :: value

The value to check.
integer(kind=int8), intent(in) :: min

The minimum value of the inclusive range.
integer(kind=int8), intent(in) :: max

The maximum value of the inclusive range.

Return Value logical

Returns .true. if value is in [min, max], otherwise .false.
